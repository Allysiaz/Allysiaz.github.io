PANDUAN FOTO PROFIL:
=====================
Untuk mengganti foto profil di Hero section:
1. Siapkan foto formal/semi-formal Anda (disarankan orientasi potret vertikal / ratio 3:4 atau 4:5).
2. Simpan foto tersebut di dalam folder ini (assets/) dengan nama:
   profile.jpg
   (atau sesuaikan ekstensi di sections/hero.html jika menggunakan profile.png).

Saat ini, website menggunakan placeholder avatar profesional (avatar-placeholder.svg) secara otomatis jika file profile.jpg belum ditemukan, sehingga tampilan tidak akan rusak.
